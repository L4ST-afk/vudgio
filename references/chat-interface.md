# 聊天 / 会话式界面判据：输入法守卫、滚动跟随与视觉语法红线

> 归属：约束满足闭环 · 第 2 步「定达成判据」的聊天/会话式界面判据卷。
> 本卷只收设计判据与交互红线；纯前端实现命令（如 keyCode 229 的具体拦截写法、Esc/双击分栏的 JS 行为）见 references/components-motion.md，不在本卷重写。（自研）
> 什么时候读：做聊天窗口、会话流、Agent 工作台、消息输入框时。（自研）

## 一、输入法守卫（交互红线）约束

来源：用户 2026-11-01 给的 6 条聊天界面优化细节 + [桌面 Agent UI](components-motion.md) 的输入法守卫与分栏章节。（自研）

- 选字期间不误发：中文/日文等输入法还在组字（composition）时，回车是“确认选字”不是“发送”。判定依据是 `isComposing` 为真或按键 `keyCode === 229`。
- 收尾宽限：组字结束后的极短窗口内（约 500ms）也不应把回车当发送——用户刚选完字、手指还在回车上。这条是防抖，不是延迟发送。（自研）
- 判据落到设计：输入框下方要有“发送”与“换行”的明确分工提示；移动端尤其要区分“回车=换行”还是“回车=发送”，默认态要可预期、不反直觉。

## 二、滚动跟随阈值（避免“消息一进来就乱跳”）约束

- 只在贴底时跟随：用户离底部 40px 以内，新消息才自动把视口带到底部；超过这个范围不自动跟随。（自研）
- 用户一滚就停：只要用户主动滚动（任意方向），立即解除自动跟随，不跟了。（自研）
- 离底超过 120px 给“跳至最新”：用户回溯阅读时，在右下角浮一个轻量按钮（如“有新回复 ↓”），点了才平滑回底并重新激活跟随——不要把回溯中的用户硬拽回去。

## 三、边框只套一层（视觉语法统一）约束

- 容器有边框，里面的控件不再加边框：卡片 / 面板 / 浮层的外框是唯一的一层边界；按钮、标签、输入这类内部控件用底色变化、内嵌阴影表达状态，不另起描边。（自研）
- 悬停用底色不用描边：鼠标悬停时控件变底色，不靠加边框，避免每次 hover 都让周围元素抖一下。（自研）
- 描边改用 `inset box-shadow`：必须描边时写 `box-shadow: inset 0 0 0 1px …` 而不是 `border`，因为 `border` 会占布局空间、改尺寸就抖；`inset` 阴影不占空间，零布局位移。（自研）

## 四、同心圆角几何约束

- 外圆角 = 内圆角 + 内边距：容器圆角 `R_out` 与内部元素圆角 `R_in` 之间必须满足 `R_out = R_in + padding`，否则内层元素会顶出容器的圆角（露出方角或留奇怪缝隙）。这条是几何对齐，不是审美偏好。（自研）
- 要 G2 平滑圆角（超椭圆）时：同心公式照用，但外层改用 `clip-path` 生成的真路径（子元素跟着整棵子树一起被裁，⛔ 用 `overflow: hidden`＋`border-radius` 顶替）；做法与坑见 [圆角几何](corner-geometry.md)。（自研）

## 五、可拖拽分栏的视觉契约约束

- 拖动时盖遮罩：拖分栏的过程中，给右侧预览盖一层透明遮罩，避免拖动期间密集重排/重绘闪烁、也防止误触内部元素。（自研）
- 闭环手势：`Esc` 恢复拖动前的比例；双击分栏回到 50/50 默认；左栏拖超过 82% 时自动收起右栏（让出整屏给主区）。这些是“分栏怎么收尾”的体验红线，不是可有可无。

## 六、长文件名的省略号约束

- 中间省略、后缀完整：`very-long-file-name-with-context….ext` 而不是把尾巴截掉——用户靠后缀认文件类型，靠前半段认内容。省略号永远落在中间，扩展名与最后一段保持可见。（自研）

## 七、达成判据与三态结论

下列判据可直接用于验收，每条带可执行的检查点：

| 判据 | 检查点 / 命令 | 阈值 |
|---|---|---|
| isComposing 误发禁令 | 检查组字时回车是否仅确认选字、不发送 | `isComposing` 为真时不得发送 |
| keyCode 229 判定 | 检查是否按 keyCode === 229 判定 | 已按 keyCode === 229 判定 |
| 收尾宽限防抖 | 检查组字结束后约 500ms 内回车是否不当发送 | 约 500ms 防抖 |
| 发送与换行分工提示 | 检查输入框下方是否有“发送”与“换行”明确分工提示 | 已有提示 |
| 移动端回车语义可预期 | 检查移动端是否明确区分“回车=换行”还是“回车=发送” | 默认态可预期、不反直觉 |
| 贴底跟随阈值 | 检查用户离底部 40px 以内是否自动把视口带到底部 | 40px 以内 |
| 超过 40px 不跟随 | 检查超过 40px 范围是否不自动跟随 | 不自动跟随 |
| 用户主动滚动解除 | 检查用户任意方向主动滚动后是否立即解除自动跟随 | 立即解除 |
| 离底 120px 跳至最新 | 检查离底超过 120px 时是否浮“有新回复 ↓”按钮 | 120px |
| 点击回底重新激活 | 检查点击按钮后是否平滑回底并重新激活跟随 | 已重新激活 |
| 边框只套一层 | 检查卡片/面板/浮层外框是否为唯一边界，内部控件是否不另起描边 | 外框唯一，内部不另起描边 |
| 悬停底色不用描边 | 检查鼠标悬停时控件是否变底色而非加边框 | 用底色不用描边 |
| inset box-shadow 描边 | 检查必须描边时是否写 box-shadow: inset 0 0 0 1px … 而不是 border | 已改用 inset box-shadow |
| 零布局位移 | 检查 inset 阴影是否不占空间、零布局位移 | 零布局位移 |
| 同心圆公式 | 检查 R_out 是否等于 R_in + padding | R_out = R_in + padding |
| G2 clip-path 真路径 | 检查超椭圆外层是否用 clip-path 生成真路径，⛔ 不用 overflow: hidden＋border-radius 顶替 | 已用 clip-path |
| 拖动时盖遮罩 | 检查拖分栏过程中右侧预览是否盖透明遮罩 | 已盖遮罩 |
| Esc 恢复比例 | 检查 Esc 是否恢复拖动前比例 | 已恢复 |
| 双击 50/50 | 检查双击分栏是否回到 50/50 默认 | 已回到 50/50 |
| 左栏 82% 收起右栏 | 检查左栏拖超过 82% 是否自动收起右栏 | 82% |
| 长文件名中间省略 | 检查省略号是否永远落在中间、后缀与最后一段是否可见 | 中间省略、后缀完整 |

三态结论：每条判据分为「过 / 不过 / 证据不足」。缺画面或缺材料一律记为「证据不足」，不得直接判「过」。
