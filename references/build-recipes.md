## 反例

按钮只有 hover 变浅、按下毫无反馈，用户点了两次；卡片里再套一张卡，每张卡配不同强调色，读的人找不到这页在说什么；表单用 placeholder 当标签，一输入提示就消失，回头不知道这格填什么。三条的根子都不在审美上——是组件语法没定。（错误原文保留）

## 读法

做或改单个组件时读；平台纵深卷（B 端、移动端、桌面、聊天）另有更严的判据时，以纵深卷为准。

## 七条通用语法

**1 按钮**

- 四档：主（一页一个）、次、三级（文字链）、危险；危险不天然最响。（活计数锚点：主档一页一个）
- 五态齐：默认 / 悬停 / 按下 / 聚焦 / 禁用 + 加载。
- 按下缩到 0.97，100–160ms 内立即生效；松开弹回，⛔ 从 0 开始。（阈值 0.97 / 100–160ms）
- 加载态换图标不换宽度，布局不跳。
- 图标与文字基线对齐，图标约为字号 1–1.25 倍。（阈值 1–1.25 倍）

**2 卡片**

- 一层容器只装一个对象；能指出它承载谁，指不出就拆。
- ⛔ 卡套卡；⛔ 每张卡不同强调色与重阴影。（⛔ 禁令）
- 靠大图和连续排版建立气氛的页面，不强塞卡片。
- 卡内只留结论；刷新口径、导出方式、操作说明下沉到交互提示或文档。

**3 表单组**

- label 常驻，placeholder 只给格式示例（`如 138 0000 0000`）。
- 错误写在该字段旁，写清问题与怎么改；⛔ 只在顶部弹一条「提交失败」。（⛔ 禁令，错误原文保留）
- 帮助文字一行，放 label 下或字段下，位置全表单统一。
- 必填用文字或统一标记，⛔ 只用红色星号。（⛔ 禁令）

**4 表格**

- 数字右对齐、等宽数字；文本左对齐。
- 行线只用一个方向（行间底线，或组上顶线），⛔ 上下都画。（⛔ 禁令）
- 列宽按内容与重要性，不被等分绑架。
- 空态、加载骨架、错误重试三样都不能缺。

**5 弹窗与浮层**

- modal 只用于需要打断或保护焦点的任务；不需要就别用。
- 定位：popover 从触发元素原点展开并跟随，modal 居中（唯一例外）。
- **跟随靠锚点，不靠监听。** 气泡、下拉、提示框优先用 CSS 锚点定位（`position-anchor`、`anchor()`、`position-try-fallbacks` 翻边兜底），由浏览器跟触发元素与滚动同步；⛔ 监听 `scroll`／`resize` 手算坐标再写样式——那会晚一帧，滚动中肉眼可见地抖。浏览器未支持时退化为原生 `popover` 的默认定位或一次性 `fixed` 取值，退路里⛔ 留常驻滚动监听。
- 遮罩可点关闭（会丢输入时二次确认）；关闭后焦点回到触发元素。
- 打开时锁滚动，关闭时恢复滚动位置。
- **语法查平台口径，别照记忆写**：原生 `<dialog>`／`popover` 已经提供焦点圈闭、`Esc` 与 back 手势、`::backdrop`、焦点回触发器 ⇒ ⛔ 不写 `role="dialog"`、`aria-modal`、手工焦点陷阱、`Esc` handler。（⛔ 禁令，标签名 `<dialog>`/`<popover`、`::backdrop`、属性名 `role="dialog"`/`aria-modal` 不改）查法见库根 `现代Web指南.md`（`retrieve dialog`／`light-dismiss-a-dialog`／`platform-controls-dismiss-dialog`，文件路径不改）。

**6 空态**

- 空态是功能的一部分，在功能设计时就画，⛔ 最后补。（⛔ 禁令）
- 内容不存在时，隐藏不生效的 tab 与筛选。
- 一句话说清这是什么、下一步做什么；给一个真实可点的动作。

**7 导航与分段控件**

- 当前项唯一；选中用一块会移动的滑块，⛔ 旧的熄灭、新的点亮。（⛔ 禁令）
- 选项宽度不同时，宽度一起过渡；首次显示直接到位，不从 0 长出来。（⛔ 禁令：不从 0 长）
- 只在悬停出现的入口，触屏与键盘必须另有路径。（⛔ 禁令）

## 结构件配方：三段装配

上面七条讲**单个组件**的语法；这一段讲**一片页面由谁拼起来**。三段各给槽位与判据，不给整页骨架——列宽、字段数量、行数都归业务，写死就变成模板了。

### 一 表单一段页怎么拼

| 槽位 | 该放什么 | 空着的后果 |
|---|---|---|
| 区块顺序 | 必填项在前、可选项收进一个折叠区（默认收起） | 一屏十几格看不出哪些必须填，用户中途放弃 |
| 字段四件 | label（常驻）／格式示例（placeholder）／帮助一句／错误位 | 帮助文字位置不统一时，用户学会忽略所有帮助 |
| 提交区 | 一处，主按钮＋取消；有草稿价值时加「保存草稿」 | 主次两个按钮散在页面首尾，用户找不到该点哪个 |
| 离开守卫 | 未保存时离开要提示，且给「留下／放弃」两选 | 误触返回键丢掉整页输入 |

判据：失焦即校验，错误写在该字段下方并说清怎么改；提交失败保留全部已填值、高亮首个出错字段并把焦点移过去；⛔ placeholder 当 label。（⛔ 禁令）字段超过 8 个仍平铺一页，就要分区或分步。（阈值 8 个）

#### 字段分层：一次只露当下要填的

外层只留此刻非填不可的，其余收在看得见的入口后面。

- **按频率分层，不按必填分层。** 每次都要填的留外层；偶尔才改的（重复、提醒、标签、权限、备注）收进一个「更多选项」。⛔ 冷门项和常用项混在同一列、只靠变淡区分——变淡仍然占位，一屏照样长。
- **收起不等于藏起来。** 折叠入口要看得见、写得清，并直接写出默认值（「重复：不重复」「提醒：无」）；不点开也知道里面是什么。⛔ 给一个「更多」或齿轮图标了事。
- **跟着选择出现，跟着改回消失。** 选了「每周」才问周几；改回「不重复」，那行连同占的高度一起撤掉。⛔ 让不适用的字段常驻置灰。
- **只折一层。** 折里再折，用户找不到回来的路；真要两层，那该分步，不是再折。
- 验收：一路用默认值提交，不点任何「更多选项」也走得完；展开后再改回，页面不留空档与灰块；折叠入口在窄屏 375 宽与 200% 字号下仍完整可见。

### 二 列表一屏扫五行还是两行

| 槽位 | 该放什么 | 空着的后果 |
|---|---|---|
| 行主体 | 主信息一处、次信息一到两处、尾随动作（≤2） | 主次同字重同色阶，读者逐行读而不是扫 |
| 分组头 | 只有真的按组读时才加（日期、状态） | 为装饰加分组头，行高被吃掉一截 |
| 批量条 | 选择模式才出现，含已选数与批量动作 | 常驻勾选框让点击目标变小，误触率上升 |
| 底部边界 | 「加载更多」或「已到底」，二者必有一个 | 无限滚动没有到底提示，用户以为还能再滚 |

判据：行高只用一档（紧凑 44–56、舒适 64–72）；主信息只靠一种手段变响（字重或色阶，不同时用）；尾随动作超过两个就收进「更多」；（阈值 ≤2 / 44–56 / 64–72）列宽按内容与重要性，⛔ 等分。（⛔ 禁令）

### 三 空状态三种空不是一个空

| 型 | 何时出现 | 必须有的句子与动作 |
|---|---|---|
| 零数据 | 还没有任何记录 | 「这里还没有 X」＋一个真实可点的创建动作 |
| 零结果 | 有数据，被筛选筛没了 | 「当前筛选下没有结果」＋「清空筛选」，并保留筛选器本身 |
| 失败 | 请求没回来 | 人话写原因＋「重试」＋小字错误码（可复制） |

判据：三型的文案不能互借——零结果给「新建」是把用户的筛选问题答成数据问题；空态出现时隐藏不生效的 tab 与筛选；插画沿项目既有语言，没有就留白，⛔ 临时找一张图撑场面。（⛔ 禁令）

## 组件动效配方

- 过渡用 `transition`，不用 `@keyframes`：可中断，连续操作从当前位置续走。（属性名 `transition` / `@keyframes` 不改）
- 首次挂载的入场用 `@starting-style`，⛔ 用 JS 加 class 触发。（⛔ 禁令，属性名 `@starting-style` 不改）
- tooltip：第一次悬停延迟 ~300ms，同一元素二次进入立即显示。（阈值 ~300ms）
- 弹出层下面有文字时，用轻微 `backdrop-filter` 模糊掩膜，不叠半透明黑。（属性名 `backdrop-filter` 不改）
- 尺寸变化用 `clip-path` 或 `transform`，⛔ 动 `width/height`。（⛔ 禁令，属性名 `clip-path`/`transform`/`width`/`height` 不改）
- 只动 `transform` 与 `opacity`；避免在动画里改变 CSS 变量的继承链。（属性名 `transform`/`opacity` 不改）
- `prefers-reduced-motion` 下状态直接到位，内容一样不少。（媒体查询名不改）
- **top layer 进出（dialog／popover／tooltip）四件必须齐**：`transition-behavior: allow-discrete` → 过渡 `overlay` 属性 → `@starting-style` 给入场起点 → `::backdrop` 单独过渡。缺一就闪或提前被裁。兼容数据与完整示例查库根 `现代Web指南.md`（`retrieve animate-to-from-top-layer`，文件路径不改）。属性名 `transition-behavior: allow-discrete` / `overlay` / `::backdrop` 不得改动。
