## 最佳实践与维护规约

1. **增量演化原则**：在具体项目中探出新桌面避坑方案时，按“触发症状 → 根因机制 → 最小解法 → 验证标准”提炼为通用模式并增补入本索引；
2. **保持解耦与通用性**：本 skill 沉淀通用交互物理、CSS 标准规范与现代桌面架构模式，避免依赖特定私有路径或私有工具链；
3. **真实运行时检验**：任何动效与阴影修复，须在对应桌面外壳（Electron / Tauri / 真实浏览器引擎）中，以真实缩放比（DPI）与真实输入设备作终验。

## 方法来源：约束满足轴

本 skill 的方法轴是「约束满足」：先列可机判约束，再写带命令／阈值的达成判据，再求满足解，最后逐条验证，三态结论为过／不过／证据不足。方向**不是必经步骤**，只是约束的一个可选解空间；评审不打审美分，只逐条验判据（`cmd` 绿 / `none` + 归因），⛔ 不给模糊分。

这条轴不是凭空落的，它从两处本地方法源合流而来，两处都在本表登记、可顺着查：
