# 路由（唯一命令正本）

一句话先落到命令，命令决定读哪几卷。⛔ 本表只在这里有一份，SKILL.md 不重复展开。

## 无参数时

列一次菜单（13 条各一行），⛔ 不自动执行任何一条；用户点一个再走。

## 三条纪律

1. **一次只加载需要的卷。** 首读一卷，其余按页面或问题出现再读；⛔ 不通读 50 卷。
2. **两条命令都像时问一次，不猜。** 「改」和「比」最容易混：改是收敛，比是发散。
3. **跨命令按顺序跑并说明。** 例：做 → 审 → 改；先建后审再修，不跳步。

## 与四型的关系

四型（说服 / 操作 / 阅读 / 体验）决定本次优先落哪组约束，命令决定这次做什么动作：

- 说服 ⇒ 记忆点约束 + 叙事约束优先
- 操作 ⇒ 扫描路径约束 + 一致性约束优先
- 阅读 ⇒ 层级约束 + 可读性约束优先
- 体验 ⇒ 主角约束 + 克制（少解释）约束优先

同一命令在不同型下的偏离见 SKILL.md 的四型表：操作型服从扫描路径，说服型才允许大胆构图。

## 平台纵深

命令不分平台，卷分。落在 B 端、移动端、桌面 Agent、聊天界面时，除首读卷外再按 SKILL.md「平台纵深」一节加载对应纵深卷，两者不冲突时都留。
