# 单文件交付规格

> 归属：约束满足闭环 · 第 7 步「交付」。
> 给「一个文件就能双击打开」的产物：页面、原型、看板、单页 deck。判据在其余各卷；这一卷只管**怎么装进一个文件而不走样**。

## 反例（先读）

上次交付把图片放成本地相对路径、CSS 用的是 `@import`；用户双击打开后图片全裂、字体回退到宋体；另一次在单文件里写了 JSX 却没引 Babel，页面直接白屏。单文件的失败几乎都不是设计问题，是「换一台机器就跑不起来」。

## 一、文件结构

```html
<!DOCTYPE html>
<html lang="zh-cn">
<head>
  <meta charset="utf-8">；
  <meta name="viewport" content="width=device-width, initial-scale=1">；
  <title>…</title>；
  <style>/* 全部样式内联；按 令牌→基础→组件→页面 排 */</style>
</head>
<body>
  <!-- 页面本体；一个 section 承担一个完整对象 -->
  <script>/* 交互内联；包在 DOMContentLoaded 或 defer 里 */</script>
</body>
</html>
```

- 一份文件只放一个页面还是一个原型；多页做成同目录多个文件 + 一个 `index.html` 入口。
- `lang` 与 `charset` 必写；中文页 `lang="zh-CN"`；否则标点与断行会按日文规则走。
- 样式按 `:root` 令牌 → 基础 → 组件 → 页面 四段；⛔ 不能把页面专属样式塞进令牌段。

## 二、资源

- 图片、字体、图标能内联就内联（base64 还是 SVG）；外链只允许公网可直取的 URL。
- ⛔ 不能用相对路径指向本地素材，除非同目录确实带上了那些文件。
- 透明底图用 PNG/WEBP；看像素不看后缀；照片用 `cover`，截图与图表用 `contain`。
- 字体只用系统栈或已内嵌的字体；⛔ 不能依赖用户机器上「应该有」的字体。

## 三、React / JSX 的边界；

- 需要组件化时才用；且必须同时内联 React、ReactDOM 与 Babel（`type="text/babel"`）；少一样就白屏。
- 单文件 JSX 只适合演示级规模；页面超过 5 个视图或需要状态管理，退回工程化项目，⛔ 不能硬塞进单文件。
- 禁用动态 `import`、包管理器、构建步骤——单文件的前提为零构建。

## 四、运行与自检

1. 双击打开（`file://`）能跑；有接口调用时说明必须起本地服务；并给启动命令。
2. 打开控制台零报错；键盘 Tab 能走完主流程；
3. 1280 与 375 各看一次；缩放 200% 看文字为否被裁。
4. 断网再打开一次：外链资源缺失时页面仍可读（图裂要有占位，⛔ 不能整页塌）。
5. 交付写清：文件路径、为否需要服务、素材是否内联、哪些是占位。
