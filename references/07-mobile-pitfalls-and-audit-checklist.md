## 一、起点说明

本规范提炼自数十个移动端生产项目的真实血泪复盘。移动端界面在打包交付或提交应用商店前，必须逐一核对以下 10 大踩坑红线与 16 项自查门禁。每条都写成可判句，配对应的检查命令与阈值。

## 二、移动端 10 大经典坑点与达成判据

### 坑点一：底部安全区丢失，主按钮被 Home Bar 截断

- 现象：底部按钮写死 `bottom: 0`，在 iPhone 全面屏上，按钮底部被系统黑色横条（Home Indicator）切掉，用户想点按钮却频繁误触滑回桌面。
- 达成判据：底部容器必须显式声明 `padding-bottom: max(16px, env(safe-area-inset-bottom))`。检查点：是否存在 `env(safe-area-inset-bottom)`；阈值：已声明。

### 坑点二：半屏浮层下的“滚动穿透”

- 现象：弹出筛选抽屉或规格面板后，用户在抽屉内上下滑动，抽屉几乎不动，底层主页面却疯狂跟随晃动。
- 达成判据：浮层打开时，通过将底层 `body` 设为 `position: fixed` 并记录原有 `scrollY` 锁死滚动；浮层关闭时精准还原。检查点：打开 Bottom Sheet 并在上方上下猛滑；阈值：底层纹丝不动。

### 坑点三：软键盘弹起遮挡输入框并挤碎布局

- 现象：页面靠下位置点击输入框，软键盘弹起瞬间把输入框盖住，或把吸底主按钮顶到屏幕中央挡住输入区域。
- 达成判据：监听输入框聚焦事件，调用 `element.scrollIntoView({ behavior: 'smooth', block: 'center' })`，且为滚动容器预留至少 `300px` 的底部垫高缓冲内边距。检查点：点击低位输入框，键盘弹起后内容是否清晰可见；阈值：输入框平滑居中滚动至视口中。

### 坑点四：iOS 边缘右滑返回手势被轮播图劫持

- 现象：页面最外侧放置横向轮播图（Swiper），用户想在屏幕左侧边缘右滑返回上一页，手势被轮播图抢走，导致无法退出页面。
- 达成判据：轮播图距离屏幕左侧边缘预留至少 `16pt` 间距，或通过手势判定排除边缘 `20pt` 内的初始触摸。检查点：真机从左向右边缘滑动测试返回上一页；阈值：左边缘 `16pt` 范围内无横滑轮播组件劫持返回。

### 坑点五：小图标触控热区过小，按压失败率极高

- 现象：关闭按钮、返回箭头只设置视觉尺寸 `16×16px`，普通成年人手指很难一次点中，用户体验烦躁。
- 达成判据：严格执行 iOS `44×44pt` / Android `48×48dp` 最小热区规则，借助内边距或 `::after` 伪元素向外扩张触控面。检查点：小图标是否通过 padding 或伪元素向外扩张；阈值：热区 `44×44pt` / `48×48dp`。

### 坑点六：桌面端复杂表格暴力移植到手机

- 现象：在手机屏幕上强塞一个包含 8 列的表格，导致整屏发生灾难性的横向晃动，主结构彻底失衡。（自研）
- 达成判据：移动端坚决将复杂表格转换为纵向结构化信息卡片（Card Grid），仅保留核心主键与状态，其余属性下钻到抽屉或详情页查看。检查点：是否存在 8 列表格强塞；阈值：不得存在。

### 坑点七：卡片阴影被父级 overflow 截断成半截黑硬线

- 现象：带有柔和弥散阴影的卡片放在横滑容器内，卡片上下两边缘的投影被父容器的 `overflow: hidden` 粗暴切断。（自研）
- 达成判据：容器周围预留至少 `offsetY + blur` 的间距余量，无法提供余量时降级为 `0.5px` 精细微边框。检查点：容器是否预留阴影外扩余量；阈值：余量 ≥ offset + blur + spread。

### 坑点八：输入框 inputmode 错误导致键盘频繁误切换

- 现象：输入纯数字手机号或验证码时，手机弹出了全尺寸的英文全键盘，用户必须手动切换到数字面板。（自研）
- 达成判据：手机号声明 `type="tel"`，纯数字声明 `inputmode="numeric"`，验证码追加 `autocomplete="one-time-code"`。检查点：`inputmode` 与 `autocomplete` 属性；阈值：手机号弹九宫格数字，验证码支持系统一键填入。

### 坑点九：输入表单弹窗点击遮罩直接静默关闭

- 现象：用户在浮层中认真填完几十个字，手指手滑碰到浮层外阴影背景，浮层瞬间关闭且数据全部清空。
- 达成判据：包含录入字段的浮层，必须禁止点击背景关闭（`maskClosable={false}`），退出必须通过点击左上角“取消”或“关闭”按钮确认。检查点：点击背景暗色遮罩，浮层是否关闭；阈值：不应关闭。

### 坑点十：弱网与断网大白屏

- 现象：在地下车库或弱网环境下打开页面，页面白屏转圈 30 秒后无任何提示直接崩溃。（自研）
- 达成判据：页面进入即展示轻量骨架屏；超过 `5秒` 未响应展示“网络连接不稳定”空态页并附带“重新加载”大按钮。检查点：模拟无数据或断网，是否有重试或去首页入口；阈值：`5秒`。

## 三、16 项移动端交付自查硬门禁（Audit Checklist）

| 编号 | 检查维度 | 验收标准 | 检查方法与判据 （自研）|
|---|---|---|---|
| 01 | 底部安全区（Home Bar） | 底部常驻按钮与 TabBar 在全面屏上不被横条遮挡 | 检查是否声明 `env(safe-area-inset-bottom)` |
| 02 | 顶部安全区（Status Bar） | 顶部导航栏不侵入刘海、灵动岛与前置摄像头 | 检查是否声明 `env(safe-area-inset-top)` |
| 03 | 最小触控热区 | 所有可点击项热区 `44×44pt`（iOS）/ `48×48dp`（Android） | 检查小图标是否通过 padding 或伪元素向外扩张 |
| 04 | 相邻按键间距 | 相邻两个可操作项留白 `8pt` | 杜绝紧贴按钮导致的连带误触 |
| 05 | 键盘防遮挡 | 聚焦靠下输入框时，输入框平滑居中滚动至视口中 | 测试点击低位输入框，验证键盘弹起后内容清晰可见 （自研）|
| 06 | 键盘类型精准 | 手机号弹九宫格数字，验证码支持系统一键填入 | 检查 `inputmode` 与 `autocomplete` 属性 （自研）|
| 07 | 手势冲突保护 | 屏幕左边缘 `16pt` 范围内无横滑轮播组件劫持返回 | 在真机从左向右边缘滑动测试返回上一页 （自研）|
| 08 | 滚动穿透锁死 | 浮层与抽屉展开时，底层页面完全不可滚动 | 打开 Bottom Sheet 并在上方上下猛滑，确认底层纹丝不动 （自研）|
| 09 | 浮层防误触丢失 | 表单录入类抽屉与对话框禁用点击遮罩关闭 | 点击背景暗色遮罩，浮层不应关闭 （自研）|
| 10 | `0.5px` 精细边框 | Retina 屏幕上边框轻盈透气，杜绝粗黑 `1px` | 检查是否采用 `0.5px` scale 或半透明 RGBA 色值 （自研）|
| 11 | 同心圆角几何法则 | 卡片与内部元素满足 `R_outer = R_inner + Padding` | 计算内外圆角差值是否等于内边距 |
| 12 | 主行动点（CTA）唯一 | 移动端一屏内最多 1 个全宽 Primary 主按钮 | 检查页面底部是否并排多个刺眼实心按钮 |
| 13 | 全屏无多余横滚 | 页面外层 `clientWidth === scrollWidth` | 左右滑动检查页面有无多余晃动和白边 （自研）|
| 14 | 图片长宽比秩序 | 列表图文严格遵循 `1:1`、`4:3` 或 `16:9` 三段式裁切 | 检查图片 `aspect-ratio` 与 `object-fit: cover` （自研）|
| 15 | 弱网与空态出口 | 空列表与网络失败具备明确文案和行动出口按钮 | 模拟无数据或断网，检查是否有重试或去首页入口 （自研）|
| 16 | 拒绝从零手搓轮子 | 弹窗、手势、抽屉复用成熟组件库 | 优先采用 React Native、shadcn/ui、vaul、lucide 方案 （自研）|

## 四、达成判据与三态结论

下列判据可直接用于验收，每条带可执行的检查点：

| 判据 | 检查点 / 命令 | 阈值 |
|---|---|---|
| 底部安全区声明 | 检查是否声明 `env(safe-area-inset-bottom)` | 已声明 |
| 顶部安全区声明 | 检查是否声明 `env(safe-area-inset-top)` | 已声明 |
| 固定底部按钮公式 | 检查 `padding-bottom: max(16px, env(safe-area-inset-bottom))` | 已声明 |
| 最小触控热区 iOS | 检查可点击项热区 | `44×44pt` |
| 最小触控热区 Android | 检查可点击项热区 | `48×48dp` |
| 相邻可点击项间距 | 检查边缘留白 | `8pt` |
| 键盘防遮挡 | 检查 `scrollIntoView` 聚焦滚动 | 输入框平滑居中 |
| 键盘缓冲内边距 | 检查底部垫高 | 至少 `300px` |
| 键盘类型手机号 | 检查 `type="tel"` 与 `inputmode="numeric"` / `autocomplete="one-time-code"` | 已声明 |
| iOS 边缘手势间距 | 检查左边缘 `16pt` 范围 | 无横滑轮播劫持 |
| 小图标热区扩张 | 检查 padding 或 `::after` 扩张 | `44×44pt` / `48×48dp` |
| 桌面表格禁令 | 检查是否存在强塞 8 列表格 | 不得存在 |
| 阴影外扩余量 | 检查容器周围 `offsetY + blur` 余量 | 余量 ≥ offset + blur + spread |
| 浮层点击遮罩禁令 | 检查 `maskClosable={false}` | 浮层不应关闭 |
| 弱网空态 | 检查超过 `5秒` 未响应的处理 | 展示空态页 + 重新加载按钮 |
| 无多余横滚 | 检查 `clientWidth === scrollWidth` | 相等 |
| 图片裁切规范 | 检查 `aspect-ratio` 与 `object-fit: cover` | 已三段式裁切 |
| 成熟组件库复用 | 检查是否从零手搓轮子 | 优先 React Native / shadcn/ui / vaul / lucide |

三态结论：每条判据分为「过 / 不过 / 证据不足」。缺画面或缺材料一律记为「证据不足」，不得直接判「过」。
