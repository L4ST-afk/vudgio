## 一、结论先行

| 层级 | 名称 | 字面 | 暗喻的功能 |
|---|---|---|---|
| **品牌** | **浮龟 / Vudgio** | 浮＝浮起、悬浮；龟＝甲壳分格、承托、慢行 | 「浮在上面的层」与「托得住它的壳」——界面就是这两样东西 |
| **动作 1** | **浮** | 浮层、浮起、悬浮态 | z 轴：overlay／dialog／drawer／bottom-sheet，以及 hover、抬升、动效的位移 |
| **动作 2** | **龟** | 甲壳分格、壳能承重、百年一行 | 栅格与模块边界／质量地板（craft floor）／验收要慢 |
| **Slogan** | **浮而不散，龟以承之。** | | |

⚠️ 一句话：**「浮」是界面的态，「龟」是界面的底**。只有浮没有龟，就是一堆飘着的卡片。

另注：网传「罗列河山共锦绣，**浮沉**沧海同行舟」两句，句首正是「罗」「浮」二字——本卷取「浮」为名，与那副流传的嵌名句**同形**；但那句**不是谢灵运写的**（温州大学沈洪保《谢灵运未写罗浮诗》判伪，详见罗蛇卷 §三·补），引用时不可署他，只可标「流传的嵌名句」。

## 二、最要紧的一条：浮而不散

界面这件事，最容易被讲成「好看」，然后就只剩「浮」。

- **浮**：层能起来——弹窗压住页面、抽屉从边上来、卡片在 hover 时抬起。这是**态**。
- **龟**：层起来之后，底下要有壳——令牌、栅格、对比度地板、组件优先级。这是**底**。

名字把「底」写进了动物里：龟不是装饰，是**壳**。壳有三件事正是本 skill 的判据层：

| 龟的哪一部分 | 界面里是什么 |
|---|---|
| **甲片的分格** | 模块边界——分格清楚，组件才不互相咬（栅格与资产可检索是它的延伸，不算第二个锚） |
| **壳的承重** | 质量地板 craft floor 这一件东西（对比度、最小字号、动效时长、不可核宣称都是它的条款，不是并列的四个锚） |
| **壳能缩进去** | 该收的地方要收：丰富度只放在内容、不放在壳 |

⚠️ 这张表是**品牌比喻的落点**，不是映射卡：每行只认一个主锚，括注里的其余项是延伸。⛔ 拿它当判据清单逐项勾——判据在 `craft-floor.md` 与 `acceptance.md`。

⇒ 「浮龟」读成一句话：**层可以浮，底必须是壳**。⛔ 反过来（有浮无壳）就是本 skill 反复拦的那种稿：亮、暗、暖三个方向都好看，但没有一条落到可验收的地板。

## 三、乌龟浮木：三层，只有一层是原义

「浮龟」另有一重佛典来历——**盲龟浮木**。它常被当成一句吉祥话引，其实有三层，只有中间那层是原义。

**第一层｜字面承托**：龟浮于海，需一段浮木才能歇。⇒ 再稳的壳，也要有东西托着——对应**底座与令牌**。

**第二层｜典故原义（人生难得）**：
- 《杂阿含经》卷十五·第 406 经：大地悉成大海，有盲龟寿无量劫，**百年一出其头**；海中有浮木，止有一孔，随风东西。「盲龟百年一出其头，当得遇此孔否？」阿难答不能。佛言：盲龟浮木虽复差违，或复相得；**愚痴凡夫漂流五趣，暂复人身，甚难于彼**。（《大正藏》第二卷，108 页下）
- 《大般涅槃经》卷二：「生世为人难，值佛世亦难，**犹如大海中盲龟，值浮孔**。」
- 《圆觉经》：「**浮木盲龟难值遇**。」

⇒ 原义是**稀有**：百年一次，孔只有一个，风还一直在吹。

**第三层｜本 skill 的反用（须标明是反用）**：
原典以「难得」劝人珍惜；本 skill 借它的**结构**，不借它的劝诫：

| 浮木盲龟的构件 | 本 skill 里对应什么 |
|---|---|
| **浮木的孔** | 验收口径——只有一个孔，口径必须唯一 |
| **龟的颈** | 实现形态——尺寸与位置要对得上孔径，不是「大概齐」 |
| **百年一遇** | ⛔ 不借：本 skill 不做「百年一遇的灵感」，要的是**每一次都落到地板上** |

所以典故在这里的作用是**反向的**：把稀缺性从「灵感」移到「判据」——灵感难遇，判据每天都该在场。

## 四、龟的姿态对应界面设计的哪几件事

| 龟的姿态 | 界面里对应什么 | 落在哪一卷 |
|---|---|---|
| **甲片分格** | 栅格、模块边界、资产可检索 | `layout-and-viewport.md`、九查的结构层 |
| **壳能承重** | 质量地板：对比度、字号、动效时长、不可核宣称 | `craft-floor.md`、`acceptance.md` |
| **百年一行（慢）** | 验收要慢：先定约束，再逐项对；评审结论必须来自双宽画面而非只读代码 | `review-rubric.md`、`task-review.md` |
| **缩壳** | 该收就收：丰富度只在内容、⛔ 不为证明规则被应用而制造 diff | `visual-language.md` |

另有一条是**龟的旧壳**：脱下来的壳留着，用来对照——对应「回滚靠冷存档快照」，不是靠 git（本目录被搬过，git 历史真丢过）。

## 五、与罗蛇的对称

| | 罗蛇 | 浮龟 |
|---|---|---|
| 管什么 | 字怎么走（行内、行间、页面） | 层怎么立（构图、层叠、底座） |
| 取的姿态 | 蛇：蜿蜒、有节、贴地 | 龟：分格、承托、慢行 |
| 共同的源 | 罗浮二山（出处见罗蛇卷 §三） | 同 |
| 合起来 | **一对错位的龟蛇＝玄武**：一个字流在下面爬，一个层在上面浮 | |

⇒ 罗浮原典里「罗山似龟、浮山似蛇」；本库把蛇配给罗、把龟配给浮，理由是**功能**，不是风雅。为什么要换位、换得对不对，见 `罗蛇Rassarpa/references/naming.md §二`。

## 六、英文名 Vudgio

- 目录名、工作区目录（`.vudgio`）、UA 串（`Vudgio-curate-media/…`）用它；正文一律写「浮龟」。
- ⚠ UA 串里的 `curate-media` 用连字符而非下划线：UA 是 HTTP 产品标识符，不是文件名；脚本文件名仍按库口径写 `curate_media.mjs`。
- ⚠️ **构词未确认**：`Vudgio` 的词源在本库没有任何记载。⛔ 别在对外文案里给它编词源。
- 它确实承担了一个工程作用：**ASCII 安全**。对比页静态壳里不许出现中文（全部文案走 i18n），壳里只能留 `Vudgio` 这个占位。

## 七、可用文案

- **主句**：浮而不散，龟以承之。
- **释义句**：浮是层，龟是壳；壳上有格、有承重、能缩回去。
- **典故句**：盲龟百年一出头，值浮木一孔——孔只有一个，所以口径只能有一个。
- **对称句**：罗蛇贴地走字，浮龟浮起承层。

## 八、诚实缺口

1. **「罗列河山共锦绣，浮沉沧海同行舟」**：该对句确在流传，确在流传，但**已判非谢灵运所作**（判伪四条与检索记录见罗蛇卷 §三·补、§八）。本卷引用时只标「流传的嵌名句」，⛔ 不署谢灵运。
2. **龟蛇分配的地域**：罗山似龟／浮山似蛇属**永嘉罗浮**的读法，不写成岭南罗浮的定说。
3. **「乌龟浮木」是反用**：原典劝「人身难得」，本 skill 只借其结构（孔的唯一性）而不借其劝诫；对外解释时须点明，否则会被读成一句吉祥话。
4. **Vudgio 构词**：见 §六，无记载。
5. 本卷只解释名字；与 `SKILL.md` 冲突时以 `SKILL.md` 胜。
