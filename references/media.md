# 素材约束

> 归属：约束满足闭环 · 第 3 步「构建满足解」· 素材与资产子域。
> 只定素材选用要过的可判约束：图从哪来、在页面担什么、如何与版面接成一体。⛔ 定方向、⛔ 比风格、⛔ 审美分；结论三态：过／不过／证据不足。

## 一、先问图担不担得起一个位置

试想只留一张图、一个标题、一个动作：哪张图能守住这个位置、通过「一眼看清什么」的判据？由此判断还需不需要更多模块。

- **差距定位**：问题出在信息与构图，还是真缺一张表达产品与品牌的图？靠更多图片、光效、动画掩盖层级问题判不过；只因代码好写就拿通用渐变与几何形状替代必要图像判不过。概念或容器结构站不住时否决当前方案，先修约束或重骨架，⛔ 用生图补救。
- **一图一约束**：图展示对象、解释关系、还是建立品牌与情绪？必须一眼看明白什么。答不上来先别找图、也别生成。图已讲清的内容文字⛔ 重复。
- **后台与工具同样判**：对象缩略图助识别、内容封面支持浏览、地图或空间图助定位、示意图解释关系——它们可能是界面最有价值的部分。纯数据任务确实不受益时保留清楚的数据表达，⛔ 硬塞气氛图。
- **顺序是先约束、再图、页面最后呼应**：主体、视角、尺度、光线、颜色、材质、留白由达成判据定；页面字体、背景、边缘处理、运动从这张图建立呼应，也可用一处受控反差突出主动作。同组图统一主体尺度、视角、光线、边缘质感，⛔ 给所有图套同个滤镜。
- **图是结构不是盒中插图**：让它跨版面分界、占满首屏或与文字叠排，做法见「融合」。
- **先放真实页面验证再延展**：素材没到位时，占位版的审美评审⛔ 算判据通过。

## 二、复用、生成、还是交给代码

- **有合适的先复用**。实际看过图再引用其特征；已有好素材围绕它设计，⛔ 为证明用了工具而重复生成。
- **自然主体先备真实位图**。植物、食物、人物、空间、自然材质担任主视觉时默认先做定制位图，或复用已看过且合约束的素材。简单矢量只用于图标、数据、结构可控的图形；需要自然观感的主视觉，⛔ 用单薄线条图标冒充成品。
- **没有就做出来**。无合适现成素材时主动做关键素材，⛔ 因写前端代码省掉。来源顺序：宿主能生图用宿主；不能则先用 `curate_media.mjs` 检索真实素材当参考，仍不够就交素材需求＋可用占位版。只用任务已授权的服务，⛔ 自接付费生图、⛔ 向用户索要密钥，按所用工具自己的输入与编辑规则。除主产品外可把地域环境、原材料肌理、工序细节做进画面给完整上下文，⛔ 只放孤立棚拍白底图。需真实材质／设计器物／历史摄影／工程测绘图／古地图／科学版画／航天实拍时，用 `curate_media.mjs` 从 Poly Haven、Wikimedia Commons、各博物馆开放馆藏（含日本国立博物馆与国会图书馆）、LOC、Wellcome、NASA 检索到 `assets/`。授权不允许进页面的条目也有用：下到不上线目录给生图当参考，取题材、年代、构图、材质线索，⛔ 让生成结果复刻原图。命令见 [工具](tools.md#检索和下载真实素材)，下载自动生成 `SOURCES.md`，据此留许可与署名。
- **需随操作实时变形的实物用多层次矢量或实时渲染配静态图**。选配器、规格切换、剖面拆解这类须随点击立即改变比例／部件／色泽的区域，只放一张不变的静态照片会让操作与画面脱节。静态图留给氛围、地域、材质特写；实时联动主体用内联 SVG（画足外轮廓受光体积、结构连接件、表面肌理三层，⛔ 单薄纯色图标）或 Canvas／3D 绘制，让每次切换在画面上立即兑现。
- **位图与代码分工**。位图管自然形态、材质、光影；代码管交互与可访问界面。文字、按钮、表单、数据标签、常规布局一律真实 HTML/CSS 排版，⛔ 让生图模型画字，⛔ 拿完整截图当可交互成品——生图画字易错、改不了、不能被选中和读屏。
- **离线只限运行时**。页面运行时⛔ 请求外部素材；制作阶段可按授权用 image-gen 生成再把成品打包到 `assets/`。⛔ 拿离线当跳过定制素材的理由。
- **确无生成能力才用替代**。无合约束现成素材且确认本任务无可用生成能力后，才用许可与实际显示质量都合格的临时替代素材或多层次矢量，附素材简报写清需补的主体、视角、材质、光向、留白、尺寸。⛔ 自动装工具、切收费服务、要用户粘密钥。
- 要转动、有物理或随视角变化见「实时 3D」；预先确定的连续变化见「视频的可选路径」。

## 三、让图承担意思

生成图最常翻的车不是画工差而是画得太满：细节越多越像图库照片，进版面没重点，也和页面沾不上。

跟产品无关的「好看场景」进版面只抢戏；处处画满细节等于没有重点。画实物或真实场景时把主体质感与光影做足，背景和放字处留干净；画抽象功能或前后变化时可把大面压成单色、白模、失焦，只让关键几处亮出颜色、光、细节。

挑能和页面「接上」的主体：单个物件能跨两块色面分界；能延伸出画面的线状物；能在上面标注的空间（模型、地图、剖面、平面图）。这样的主体之后能和页面里的线、标注、区块连成一体，一张自给自足的风景照做不到。

### 提示词六段式（按序，每项一两句）

1. **主体与表现形式**：什么东西、用什么体裁（照片／插画／模型／图解），体裁由约束推出。
2. **构图与留白**：主体位置与占比、哪块留空给文字；按已选骨架写主体区域与占比，留字那块要完全干净——无高光、反光、杂乱纹理。
3. **安全距离**：主体、托台、阴影不贴文字边缘，留约 10% 空隙，防窄屏时文字压到物体。
4. **背景**：直接写页面实际十六进制色值，或要求纯透明背景；色值一致则边缘自然融入，⛔ 另用 CSS 遮罩去修。
5. **材质与光**：主光方向、辅光、质感；同页多图用同一光向；地面反光向留白侧自然衰减，⛔ 横扫到文字区。
6. **排除项**：不要任何文字、标志、伪代码、界面截图或多余漂浮物；小件图标或透明图注明「不要地面投影」，外部投影交前端 CSS `filter: drop-shadow(...)` 控制。

### 生成后放进页面再判

在真实页面、真实尺寸里看，⛔ 在图片查看器里判。单独看好的图进版面常主体太满、朝向不对、留白在错位置。不对就改提示词重新生成并写清改什么（如「主体右移、左边留一半」「去掉地面反光、背景换页面色值」），⛔ 围着一张不合适的图改版式。每轮只生成少量有明确差异的候选，按预写的主体／构图／材质筛，⛔ 反复随机抽卡；同批挑最能排版的一张，⛔ 挑细节最多的。

【A/B 共用素材】各版本用同一批原图与同等质量导出，只改被测变量；⛔ 拿定制位图对低质量替代图，以免把素材差距误判为方案差距。

## 四、让图和页面接成一体

- **背景融合**：要融进背景的主视觉与大图不加框、不关进圆角卡片；从图四角取色让页面背景用同值，或用 CSS 遮罩／导出渐隐把四边淡出到背景色。纯色背景时提示词底色与网页一致，边缘自然接上。
- **透明图**：先放最终背景上查边缘、白边、残留棋盘格；查透明通道要看像素，⛔ 看文件后缀。阴影不烘焙在图里，由页面按实际背景加投影，换背景也对。
- **跨结构**：透明物件放在两个色块或区块分界线上，让它同时属于两边。
- **图与代码接力**：生成图负责代码做不出的材质与光（金属、玻璃、模型、光影），代码负责精确、可编辑、会延续的部分（从图延伸的线、路径、标注）。图里本该延续到页面的那段就裁掉改用矢量接着画，这样能准确穿版面、带真实文字、在不同宽度重新走线。
- **标注**：图上标注用细引线加文字，⛔ 带底色阴影的气泡卡片；引线端点对准图里真实位置——图在版面用固定尺寸位置，按图片像素换算坐标。窄屏隐藏标注或改成图下列表，⛔ 让它漂到错误位置。
- **窄屏裁切**：⛔ 把整张大场景等比缩到看不清；从原图裁焦点区另存给窄屏，或用对象定位对准焦点。桌面与手机两种裁切都要保住承载信息的几处。
- **一图多用**：结尾或其他区块可用同图局部特写，比再生成一张光线风格对不上的更统一。

## 五、让一张画当舞台

与上一节相反：图不讲信息只给气氛，界面黑白克制，全页只用一种有笔触的画当唯一颜色来源。

- 画当舞台、界面在上面演示：真实界面简化版放画上，画从四周露出；滚动时画固定只换前面的界面内容，和「滚动叙事」接得上。
- 大胆裁切：只留画的一角或局部，接近抽象、不抢界面；题材不必和产品字面相关但气质要对。
- 松紧互衬：画越松界面越要精确干净，两者同现彼此都更好看。
- 用得少：一张画贯穿全页或只在两三处出现（如价格卡顶端、页脚），⛔ 每区块配一张；同页画统一画种与笔触。
- 演示用简化过的真实界面：次要内容虚化或换骨架，只把要讲的那处做清楚；数字对比直接用界面元素画（如两条长短不同的进度条），⛔ 另做图表。

## 六、异质素材单色化

引入历史画作、雕像肖像、外部摄影时彩色位图易与界面主题色冲突，按两法收拢到当前约束：

- **单色映射**：转黑白高对比后把暗部亮部映射到页面主色与底色。
- **网点与点阵抖动**：对写实图做半色调网点化或微弱扫描线，消解写实质感让它与排版网格共处。

## 七、抽象技术的主视觉

缺产品截图时⛔ 回退到通用彩色发光球或大渐变。从产品处理的东西找有形对象：它读写的数据长什么样、替代的那件工具或那道工序是什么、用户手边有什么。表现形式满足两条：大面积色阶平稳、文字压得住；画面里的线与标尺能由 SVG/CSS 接着画。找不到有形对象时主视觉交给排版本身。

## 八、成套素材

游戏、收集、养成类要的不是一张配图，而是一整套会被反复摆放、翻转、比较的素材。

- 先写风格说明：画法、视角、光向、材质、比例、色板各一句，同批提示词都按它写。
- 同系列靠轮廓区分：统一比例与光向，用耳朵、道具、配饰等轮廓特征区分个体，⛔ 只换颜色；缩到实际显示尺寸还要一眼分开。
- 状态序列从同一素材改：生长阶段、正反面、开壳前后、不同动作都以第一张为参考图编辑变体，保持同一角色，⛔ 逐状态独立生成；各状态落地点对齐同一基线。
- 透明图集按轮廓切：格子间留透明间距，按实际轮廓裁切，⛔ 按格子均分（会切掉树冠、带进邻格残片）；查 alpha 像素不看预览背景色，再放最终背景看边缘。
- 贴到物体上两面成立：会翻转、落下、转侧面的素材正背面都要有，边缘沿轮廓闭合；受光交场景，⛔ 在图里烘焙和场景方向相反的光影。

## 九、真实贴图与科学工程素材

读 `--sheet` 联系表 PNG 挑，`imageUrl` 用于下载；`look` 的四边色、纸底、干净区域直接对应背景融合、正片叠底、压字位置。Poly Haven 的 `textureMaps.diffuse.url` 才是表面颜色贴图，`roughness`／`normal` 供实时材质粗糙度与法线；渲染球与模型预览图⛔ 当重复铺贴。

- Diffuse JPG 用于 CSS `background-repeat: repeat` 或 SVG `<pattern>`，最终尺寸查四边接缝与重复频率；部分素材只沿一轴重复，⛔ 只看缩略图就认定双轴无缝。
- Three.js 颜色贴图用 sRGB、粗糙度与法线用线性数据；工具选 OpenGL 法线，按模型 UV 与实际光照查方向；重复材质设两轴 RepeatWrapping；模型 glTF 依赖清单里的 UV 贴图用于该模型，⛔ 当无缝材质。
- 测绘只选 LOC hh 图纸资源，照片、调查说明、图纸分开看。地图与版画 IIIF 原图尺寸与下载尺寸可能不同，以下载输出宽高判断能否承载页面放大与标注。
- NASA 视频检索排除标题或关键词明确标为动画、仿真、可视化的项，仍要看片确认实拍；首帧 poster 是静态回退，背景播放、循环、裁切先在真实页面查。
- 许可证跟素材记录走：Poly Haven 出 CC0 与信源署名；Wellcome 留条目许可；LOC ⛔ 推定所有条目无版权限制；Met／AIC／Cleveland／Rijksmuseum 只取公有领域或 CC0；Japan Search 只取 CC0、公有领域、CC BY、CC BY-SA；ColBase 按要求署「出典：ColBase」；Commons 按每文件自己的许可，BY-SA 改色或合成后同许可共享；V&A 公开 API 可访问高清图，但公开访问≠取得首页、商用或高清发布授权，标 `reference`；NASA 保留第三方署名与限制。官方条款随 `SOURCES.md` 保留，需展示署名时放页脚或项目素材说明。

## 十、实时 3D

三类情况才用：用户要转动检视的对象；堆叠、碰撞、推挤、摆动这类物理；玻璃、金属、透明塑料这类随视角变化的材质。一张生成图能表达的、或只为显得高级的⛔ 用。

- 用 three.js 这类成熟引擎，需物理再配刚体库；生成图当贴图、精灵或环境光来源，代码管空间、运动、受力。
- 验收看画面不看用没用库：静帧看得出体积、透视、接触阴影、材质区分；录屏里运动连续、力能传到被推物体上。
- 新小样把库下到任务目录 `vendor/` 并附许可证，⛔ 引 CDN；存量项目按已有依赖方式引入。以模块方式引入的页面与贴图通过本地服务器打开；要求双击即开时打包成普通脚本，贴图内联或同目录。
- 设备像素比上限 2；页面隐藏或滚出视口停帧；拿不到 WebGL 时显示同场景静态图；减少动态效果时照常算结果，只关镜头晃动与装饰演出。
- 截图前确认画布真画出内容，见 [工具](tools.md)。

## 十一、视频的可选路径

要一段叠在页面上循环播放的素材时先查三样：首尾接不接得上、主体边缘干不干净、背景处理得怎么样。单色背景生成再抠像只是可试办法之一：透明与反光物体抠完可能丢边或带背景色，要放最终页面背景上看。

连几段成一段叙事时可拿前段末帧当下段首帧，或事先统一各段关键帧。播放进度由滚动或手势控制时查跳到任意一帧、倒播、加载速度与内存占用，⛔ 默认把整段视频解码成一张张大图。

玻璃、水晶这类要折射透光的先在最终页面背景色上生成，让折射与投影烘焙进素材再用视频抠像去背景；直接绿幕生成再抠，折射会带绿。预渲染的折射与光照只对应生成时的背景，⛔ 承诺随任意页面内容产生实时物理效果。

透明底视频与图片一样可跨在两个区块分界，做法见第四节。

## 十二、文件与说明

- 生成、下载、用户给的图进页面前按显示尺寸 2 倍导出，⛔ 直接内嵌原始大图；不透明图用 JPEG 或 WebP、透明图用 WebP 或 PNG，单张控制在几百 KB 内；内嵌 data URL 后再大约三分之一。压缩、缩放、多尺寸 `srcset`、比例裁切、透明裁边用 `node <skill>/scripts/prep_image.mjs` 一次批量完成，用法看 `--help`。
- 留原图与处理后版本、生成图记提示词、工具明确提供的模型与实际成本（费用或积分），未提供的标「未提供」，⛔ 估算。所有素材记来源、用途、处理方式，分清复用、裁切、生成、后处理。
- 生成图与替代素材⛔ 冒充真实产品截图、真实场所、真实人物或产品证据。
