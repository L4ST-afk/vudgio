# 界面特效：流光、点阵、流动渐变与着色器

> 归属：约束满足闭环 · 第 3 步「构建满足解」中的程序化特效选取与降级判据。
> 特效不是装饰预算，是注意力预算。一处做对，胜过五处都做。

## 一、先过三道闸（不过就别做）

1. **这块面是说服型或体验型**。操作型界面（后台、设置、工具、编辑器）里做常驻流光，是在给要干活的人加干扰；那里最多允许一种「状态性动效」（提交中、成功）。
2. **全页只有一个记忆点**。判据：能一句话说出「用户会记住哪一处」；说不出，或数出两处以上，就删到一处。两处特效等于没有特效。
3. **有静态等价物**。关掉动画后这一处仍成立（图、渐变、纹理、排版还在），否则它在截图、打印、低端设备、降级浏览器上直接消失——那时页面会塌成一个空洞。

## 二、四类做法与各自判据

| 类型 | 适合用在哪 | 做法判据 | 常见错法 |
|---|---|---|---|
| **流光 / 扫光** | 主视觉、主按钮 hover、进度条 | 一次性扫过，不常驻呼吸；一个页面只给一个元素；周期 ≥ 2s，扫过宽度不超过承载它的元素 | 常驻呼吸灯（看三秒就想关）、给每个按钮都加 |
| **点阵 / 网点** | 背景、区块过渡、纹理 | 网格随视口缩放，2x 屏下不糊成灰；点在深色底要有独立亮度，不靠透明度硬扛 | 用一张位图平铺、放大后起锯齿 |
| **流动渐变** | 大面积背景、渐变占位图 | 用 `conic` / `radial` ＋ 位移或角度动画；⛔ 不逐帧改 `background-color`（每帧重绘） | 四五种颜色一起漂，成彩虹噪音 |
| **着色器 / Canvas** | 一镜到底首屏、粒子、流体 | 只包一个组件，不铺满整页；帧时间 ≤ 16ms；像素比按 `min(devicePixelRatio, 2)` 上限 | 拿 shader 当背景，滚动时和内容抢帧 |

## 三、性能与降级（硬线）

- **能动的属性只有 `transform` 与 `opacity`**。动 `width/height/top/left/filter` 的，一律改成 transform 或预先裁好。
- **降级顺序写死**：着色器 → Canvas 2D 静态帧 → CSS 渐变 → 纯色。每一级都要能出图，不是「加载中」。
- **`prefers-reduced-motion: reduce` 时全停**，保留静态版本，不留残影或半透明叠层。
- **闪烁 ≤ 3 次/秒**（光敏性癫痫线），闪色不超过两种。
- 移动端同屏特效不超过一处；低端机建议把着色器整段替换为静态图。

## 四、验收

- **录 10 秒屏，不只截一帧**：中断、起播、重播三个瞬间都要看。
- 在 **100% 与 200% 缩放**、浅色底与深色底各看一次；深色底的发光常在浅色底变成脏灰。
- **关掉动效再截一张**，检查静态是否仍成立；不成立说明特效在承担信息，改成素材或排版承担。
- 连续 3 秒掉帧即降级到下一档，不接受「大部分时候是流畅的」。
