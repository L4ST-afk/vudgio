## 一、起点说明

移动端页面不能照搬 B 端 Web 桌面的分栏和复杂侧边栏。“一屏只做一件事，纵向流动顺畅，触底无缝加载”是移动端页面的黄金铁律。（自研）

## 二、移动端五大经典页面原型满足解

下表把五大页面原型的结构与满足解要点写成可判句：

| 原型名称 | 结构描述 | 满足解要点 |
|---|---|---|
| 信息流列表页（Feed List） | 吸顶搜索栏 + 分段 Tab + 单列/双列卡片 + 触底无限加载 | 吸顶搜索栏，分段 Tab，单列或双列卡片，触底无限加载 |
| 沉浸式图文详情页（Media Detail） | 顶部透明/动态渐变导航 + 轮播大图 + 底部固定 CTA | 顶部透明或动态渐变导航，轮播大图，底部固定 CTA |
| 紧凑表单向导页（Form Wizard） | 单屏 `3–5` 项输入 + 标签靠左/置顶 + 底部全宽按钮 | 单屏 `3–5` 项输入，标签靠左或置顶，底部全宽按钮 |
| 个人中心与九宫格（Profile & Grouped Cells） | 头部资产大卡片 + 横向指标组 + 分组圆角单元格列表 | 头部资产大卡片，横向指标组，分组圆角单元格列表 |
| 移动端空态与异常页（Empty & Exception） | 简洁插画 + 说明原因 + 单一主行动出口 | 简洁插画，说明原因，单一主行动出口 |

## 三、信息流列表页：下拉刷新与触底加载满足解

信息流列表是移动端用户停留时间最长的场景。（自研）

### 1. 结构骨架

信息流列表页的层级结构为：MobileScreenLayout → MobileTopBar（搜索输入框 + 扫码/通知图标）→ SegmentedTabs（高频分类标签栏，水平支持横滑）→ FeedScrollView（可滚动主容器，内含 PullToRefreshIndicator 下拉加载微动画、FeedCardItem* 单列/双列卡片、InfiniteLoadTrigger 触底骨架屏或“正在加载更多...”）：

```
MobileScreenLayout /*自研*/
├── MobileTopBar（搜索输入框 + 扫码/通知图标）
├── SegmentedTabs（高频分类标签栏，水平支持横滑）
└── FeedScrollView（可滚动主容器）
    ├── PullToRefreshIndicator（下拉加载微动画，如弹性小齿轮）
    ├── FeedCardItem*（单列图文卡片或双列瀑布流）
    └── InfiniteLoadTrigger（触底骨架屏或“正在加载更多...”）
```

### 2. 性能与虚拟列表满足解

- 当列表超过 `50` 条项时：移动端内存极易被大量 DOM 节点撑爆导致掉帧发热。必须采用虚拟滚动（Virtual List），仅渲染当前可视窗口内的 `8–10` 个 DOM 节点，上下节点动态回收复用。（自研）
- 图片懒加载（Lazy Loading）：图片进入视口前展示柔和占位底色，进入视口 `150px` 内再拉取真实资源，必须使用 WebP 格式压缩。

## 四、图片三段式裁切法则满足解

移动端手机相册拍摄的照片长宽比五花八门（`1:1`、`4:3`、`16:9`、`9:16` 全景高图）。为了让卡片列表保持高度严谨的视觉秩序，必须执行三段式裁切规则：（自研）

| 原图高宽比（H:W） | 判定形态 | 裁切与展示策略 | 适用场景 |
|---|---|---|---|
| `H:W > 4/3` | 高图 / 竖屏长图 | 裁切上下两端，保留核心中央，以 `4:3` 或 `3:2` 竖直比例展示 | 社区个人晒单、竖屏人像写真、海报 |
| `3/4 ≤ H:W ≤ 4/3` | 标准方图 | 统一按 `1:1` 正方形居中裁切展示 | 电商商品主图、外卖菜品列表、头像 |
| `H:W < 3/4` | 宽幅扁图 / 横照 | 统一按 `16:9` 或 `4:3` 横图居中展示 | 资讯封面图、视频播放封面、横幅 Banner |

## 五、底部常驻操作栏与主 CTA 满足解

在电商购买页、打车确认页、工单审批页中，底部主行动按钮（CTA）的交互细节直接决定转化率。

### 1. 布局规范

- 容器高度通常为 `56pt–64pt`，加上底部的 `34pt` 安全区，总高度约为 `90pt–98pt`。
- 单一强动作（如“立即支付”、“提交申请”）：采用全宽圆角主按钮（高度 `44–48pt`，圆角 `8–12pt` 或全圆角）。
- 双动作分流（如“加入购物车”与“立即购买”）：左右平铺，左侧采用辅助次色胶囊，右侧采用强调品牌主色胶囊，左浅右深。

### 2. 避让与透明渐变

- 底部常驻栏背景必须采用高模糊毛玻璃（Backdrop Blur `16px`）配合半透明白底（`rgba(255, 255, 255, 0.9)`），上方加上一条 `0.5px` 精细微边框，确保页面内容在滚到栏后时隐约透出深度，又不影响操作识别度。

## 六、达成判据与三态结论

下列判据可直接用于验收，每条带可执行的检查点：

| 判据 | 检查点 / 命令 | 阈值 |
|---|---|---|
| 一屏只做一件事 | 检查页面是否聚焦单一任务 | 一屏一件事 |
| 纵向流动顺畅 | 检查页面是否纵向流动 | 顺畅 |
| 触底无缝加载 | 检查触底是否无缝加载 | 无缝加载 |
| 信息流列表页结构 | 检查是否包含吸顶搜索栏、分段 Tab、单列/双列卡片、触底无限加载 | 结构完整 |
| 详情页导航 | 检查顶部是否透明/动态渐变导航 | 已采用 |
| 详情页轮播大图 | 检查是否包含轮播大图 | 已包含 |
| 详情页底部固定 CTA | 检查是否有底部固定 CTA | 已固定 |
| 表单向导页单屏字段 | 检查单屏输入项数量 | `3–5` 项 |
| 表单向导页标签 | 检查标签靠左或置顶 | 已采用 |
| 表单向导页底部按钮 | 检查是否底部全宽按钮 | 已采用 |
| 个人中心头部资产卡片 | 检查是否有头部资产大卡片 | 已采用 |
| 个人中心横向指标组 | 检查是否有横向指标组 | 已采用 |
| 个人中心分组圆角单元格列表 | 检查是否有分组圆角单元格列表 | 已采用 |
| 空态页插画 | 检查是否有简洁插画 | 已包含 |
| 空态页说明原因 | 检查是否说明原因 | 已说明 |
| 空态页单一主行动出口 | 检查是否有单一主行动出口 | 已包含 |
| 虚拟列表阈值 | 检查列表超过 `50` 条项时是否采用虚拟滚动 | 必须采用虚拟滚动 |
| 虚拟列表渲染节点数 | 检查当前可视窗口内渲染的 DOM 节点 | `8–10` 个 |
| 图片懒加载占位 | 检查图片进入视口前是否展示柔和占位底色 | 已展示 |
| 图片懒加载触发距离 | 检查进入视口前的拉取距离 | `150px` |
| 图片压缩格式 | 检查是否使用 WebP 格式压缩 | 必须使用 WebP |
| 图片裁切 `H:W > 4/3` | 检查高图是否裁切上下两端保留核心中央，以 `4:3` 或 `3:2` 竖直比例展示 | 已按规则裁切 |
| 图片裁切 `3/4 ≤ H:W ≤ 4/3` | 检查标准方图是否统一按 `1:1` 正方形居中裁切展示 | 已按规则裁切 |
| 图片裁切 `H:W < 3/4` | 检查宽幅扁图是否统一按 `16:9` 或 `4:3` 横图居中展示 | 已按规则裁切 |
| 底部常驻栏容器高度 | 检查容器高度 | `56pt–64pt` |
| 底部常驻栏总高度 | 检查加上 `34pt` 安全区后的总高度 | `90pt–98pt` |
| 单一强动作按钮 | 检查全宽圆角主按钮高度与圆角 | 高度 `44–48pt`，圆角 `8–12pt` 或全圆角 |
| 双动作分流按钮 | 检查左右平铺、左辅助次色胶囊、右强调品牌主色胶囊、左浅右深 | 已采用 |
| 底部常驻栏背景 | 检查高模糊毛玻璃与半透明白底 | Backdrop Blur `16px`，`rgba(255, 255, 255, 0.9)` |
| 底部常驻栏边框 | 检查上方是否加 `0.5px` 精细微边框 | 已加 `0.5px` 微边框 |

三态结论：每条判据分为「过 / 不过 / 证据不足」。缺画面或缺材料一律记为「证据不足」，不得直接判「过」。
