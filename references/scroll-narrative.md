# 滚动约束

> 归属：约束满足闭环 · 第 3 步「构建满足解」· 滚动动效子域。
> 本卷给一组**可判定的滚动约束**，以及满足这些约束的已知手法。先读 [动效](motion.md) 的时长与手感表；本卷不决定视觉方向，不做审美打分。结论只有三态：过 / 不过 / 证据不足。

## 适用范围与两条硬约束

先判要不要读本卷：落地页、品牌页、发布页、展览页要验滚动约束；文档、文章、工具、后台⛔ 不适用，直接跳过。

任何要过验的页面，先满足两条，缺一即不过：

1. 首屏之下的每个区块，滚到位时出场一次；
2. 全页至少有一段**滑动驱动叙事**，让主角在滚动过程中发生肉眼可见的变化。

「变化」的门槛：缩放、拆解、变形、穿过或形状接力才算；一个点沿线移动、节点逐个点亮只算叙事里的细节，⛔ 单独顶替主叙事。满足解从下面的手法库里选，写进分镜并说明理由；⛔ 每页默认锁住首屏缩放。

## 手法库一：首屏的两种解法

首屏怎么动，取决于首屏装的是什么。两种解法互斥，选一即可。

### 固定舞台做景深

适用条件：首屏有明确的前后景层次。

约束：
- 固定区段的滚动行程 100–200vh，窄屏可压到 80–120vh；
- 至少两层以不同速度或方向运动，背景最慢、前景最快；
- 主层幅度 ≥15% 缩放或 ≥15vh 位移，低于此值肉眼与普通滚动无异，判不过；
- 大标题当图形层可缩放视差；正文、按钮、表单⛔ 不缩放、不做视差，固定后须保持可读可点；
- 结束态要交给下一节：主视觉收进下一节位置、标题退成纹理，或让出通路；⛔ 固定结束后整块被推走。

排除条件：首屏是满版品牌字标 ⇒ 改用下一种；首屏是满版文字、产品界面或纯排版 ⇒ 景深未必合适，把叙事放到后面。

### 字标收进导航

适用条件：首屏就是品牌字标本身，且字短、字形有性格（工作室、品牌、作品集）。

约束：
- 首屏只放这一个字标，撑满版心，窄屏仍一行撑满；导航里⛔ 再放第二个标志；
- 滚动行程 60–100vh，字标沿路径缩到导航标志的实际位置与尺寸，往回滚可逆；结束态就是导航标志，交接处⛔ 跳变；
- 缩放用对同一元素做变换，⛔ 改字号动画；字标用 SVG 或按容器宽度算出的字号；
- 字标让出首屏的同时下一节已进入画面，⛔ 留整屏空白；
- 这一段本身即算满足「滑动驱动叙事」，同页⛔ 再叠景深；
- 减少动态效果时：字标留在首屏不缩放，导航从一开始就显示标志。

## 手法库二：区块出场

首屏以下每个区块滚到位置时出场一次，往回滚不重播。出场方式必须从该区块的内容与材质推导，并符合物理直觉（重的过冲后稳住、轻的有空气阻力、机械的咔嗒到位）。

| 区块内容 | 满足条件的一种出场 |
| --- | --- |
| 卡片、实物、价格牌 | 带重量落下后稳住，过冲手感取 [动效](motion.md)；后一张由前一张带出 |
| 列表、时间线、步骤 | 沿阅读方向依次展开，连接线先画、节点后落 |
| 数字、指标 | 滚到目标值，高位先停末位后停；不从 0 起跳者用原值起滚 |
| 线条、图表、路径 | 沿数据或流程方向描出，端点落定时轻微放大 |
| 图片、照片 | 遮罩从主体方向揭开，图片从 1.08 回缩到 1 |
| 纸、布、标签 | 先快后慢，带一点旋转后摆正，像放到桌上 |
| 金属、机械、硬件 | 短促到位、无软弹，可带一次很小的回震 |
| 大标题、口号 | 按词或按行从遮罩升起，字距由略松收紧 |

配套约束：
- 重点区块单独设计出场，普通区块统一克制节奏；⛔ 全页从头到尾套同一个淡入上移；
- 曲线用弹簧或惯性，参数按材质从 [动效](motion.md) 手感表取，⛔ 默认 ease；
- 主角先到、其余被带出，间隔 40–80ms，单区块出场总长 ≤900ms。

## 手法库三：滑动叙事与镜头

### 一镜到底

整段不切镜头，一个主角从头走到尾（产品、线、形状或字皆可）。每一步长成、变成或让出下一画面：推近看细节、拉远看全貌、转过去看背面、穿过去进入下一场景。

硬约束：
- 主角从产品本身找——它处理的那样东西；⛔ 用通用漂浮几何充数。找不到专属主角就退回转场手法；
- 每个镜头留一段静止，文字在静止时出现；⛔ 边动边读；
- 视差只在画面本就有远近层次时使用：越近动得越多、差别要小；正文、按钮、表单⛔ 视差；大标题当图形层时走首屏景那套；
- 转场手法（圆扩开、推图穿过、背景色随章节变、宣言逐字亮）每种一页只用一次；
- 倒着滚也成立：每帧只由滚动位置决定，往回滚自然倒放，刷新或跳到中段画面正确；⛔ 接管用户滚动；
- 长段落前给跳过入口；减少动态效果时把静止画面排成普通区块；
- 需要生成视频或序列帧才能做到的效果（角色转身、产品拆解、镜头穿越），说明这条路并把素材列为交付前提；CSS／SVG／着色器能做的仍自己做；同一次对话只提一次。

## 两种触发模式的判定

滚动带来的变化分两类，验的时候先归类再套约束。

| 模式 | 定义 | 约束 |
| --- | --- | --- |
| **滑动驱动** Scroll-Driven | 动画进程与滚动距离严格 1:1（Scrub）；用户停则停、回滚则倒放 | 首屏景深、一镜到底、3D 变换、模型解构只用此模式；除首屏景深外，一镜到底一页最多一段 |
| **滑动触发** Scroll-Triggered | 元素进入视口阈值时触发一段按自身时长播放的独立动画，何时播完由代码定，不跟滚动条 | 默认单向一次性（Once）：触发后样式固定，回滚不重播不复位；离开重置（Reset on Leave）仅强节奏纯展示页且完全移出视口后允许，⛔ 在视口临界点反复触发 |

## 平滑滚动与整屏分段

- 平滑滚动只改善滚动手感，⛔ 算作动效。用 Lenis 之类消掉滚轮跳动，让滑动驱动与视差均匀；后台、仪表盘、表单、长文档⛔ 开全局平滑滚动，保留原生即时响应。
- 整屏分段（Snap Scroll）——隐藏滚动条、一次滑动切整屏——只用于特定全屏展厅与作品封面；常规业务和长文本⛔ 用。

## 实现约束

滚动动效用成熟动效库或平台原生方案实现，⛔ 手写滚动监听与逐帧计算。

**原生优先判定**：宿主已提供滚动驱动动画原生方案、目标视口支持时，优先用原生，⛔ 一上手就上动效库；原生不可用、需要复杂镜头接力或要锁版本离线时走下面的库方案（GSAP 也是合格 fallback）。原生方案必须带特性检测与降级，⛔ 无检测裸用。原生语法、兼容数据与降级写法查库根 `现代Web指南.md`（`retrieve scrollytelling` / `scroll-entry-exit-effects` / `parallax-scroll-effects`）；⛔ 把指南正文抄进本卷，⛔ 用功能不全的 `scroll-timeline-polyfill`。

- 无框架页面：GSAP；滚动用 ScrollTrigger（`scrub` 滑动驱动、`once` 滑动触发、`pin` 固定舞台），拆字用 SplitText，换位用 Flip。平滑滚动用 Lenis 并接进同一时钟：`lenis.on('scroll', ScrollTrigger.update)`、`gsap.ticker.add((t) => lenis.raf(t * 1000))`、`gsap.ticker.lagSmoothing(0)`。GSAP 及其插件免费。
- React／Vue 等项目：沿用已有动效库（Motion、GSAP 等）；没有才加 GSAP，⛔ 另写一套。
- 要离线打开：库文件按固定版本放进作品目录本地引用，⛔ 依赖 CDN。
- 减少动态效果：用 `gsap.matchMedia()` 分两套；减少时不固定、不缩放，所有区块直接到位，主叙事排成按顺序的静止画面。
- 只动 transform／opacity／filter；固定舞台外层高度即该段滚动行程；离屏动画由库自动暂停。窄屏可缩短行程、降低幅度，但选定手法须保留。

## 验收

从头滚到底、再滚回去各看一遍，逐条判：往回滚是否倒放；跳到中段刷新画面是否正确；文字是否在静止时出现；窄屏选定手法是否都在；开启「减少动态效果」后内容是否直接可读。缺画面判证据不足，⛔ 猜过。
