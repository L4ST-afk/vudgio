# 玻璃：判据、账目与降级

> 归属：约束满足闭环 · D 判据 ＋ S 求解。玻璃是**强调**手段，不是基调；本卷给的是能机判的数，不是「更像苹果」的感觉。
> 触发：只要用户的界面里出现 `backdrop-filter`／`blur(...)`／半透明卡片／磨砂浮层／frosted／glass／毛玻璃，**直接进本卷**，不再问要不要做玻璃——改法由下面的判据定。
> 成本与形状（固定 vs 动态、预计算法线 vs 实时着色器）见 [材质](materials.md) §三；本卷只管数值、结构与降级。

## 一、先判该不该有玻璃（不过就别做）

三层玻璃叠上去读起来像浓雾时，问题通常不在参数，在这块面本来就不该透。

| 该用 | 不该用 |
|---|---|
| 顶栏／浮动导航、浮层容器、压在图像上的小卡与控制件 | 正文区、表单主体、长列表、任何大段阅读 |

判据不是形容词，是这一条：**把真实文字压上去，在实际背景（图片、渐变、会动的内容）里看一次对比度**。玻璃底下是什么色不归你管，所以它和纯色块不是一回事。

## 二、三层结构（缺一条就是蒙版，不是玻璃）

一块可交付的玻璃 = **底 + 描边 + 光**，缺哪条都能机判出来：

```css
.glass{
  background: var(--glass-tint);                      /* ① 半透明底，alpha .18–.40 */
  backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-sat));   /* ② 真模糊 */
  border: 1px solid var(--glass-edge);                /* ③ 边缘高光 .35–.70 */
  box-shadow: 0 6px 16px rgba(0,0,0,.14),             /* ④ 落地影（暖深色，不用纯灰） */
              inset 2px 2px 1px rgba(255,255,255,.5); /* ⑤ 顶部内高光：厚度感 */
}
```

## 三、数值区间（八个变量，改一处全页生效）

| 变量 | 作用 | 安全区间 | 硬线 |
|---|---|---|---|
| `--glass-blur` | 背景模糊半径 | 4–8px | **>12px 报 E**；>9px 报 W |
| `--glass-tint` | 半透明底色 | alpha `.18–.40` | 只有 blur 没有底 = W（模糊冒充玻璃） |
| `--glass-edge` | 边缘高光描边 | alpha `.35–.70` | 无描边且无 inset 高光 = W |
| `--glass-sat` | 背景饱和增益 | `1.0–1.35` | 过高会把品牌色染脏 |
| `--glass-radius` | 圆角 | 16–28px | 胶囊控件另按 50% 算 |

数值不是审美：上限来自「投影仪 + 老笔记本上不能糊成一片」，不是来自参考图。

## 四、同屏账目（每屏真实 backdrop ≤ 3）

一层 backdrop 就是一次全屏采样。按屏数，不按全页数：

| 页面 | 账目 |
|---|---|
| 封面类（1 玻璃卡 + 导航） | 2 |
| 列表／问答类（选项 pill 不带 backdrop） | 1 + 导航 |
| 常规页（≤2 玻璃卡 + 导航） | ≤3 |

超过 3 层，脚本直接 E 级 FAIL。要更多「玻璃感」，先把不承担信息的那层改实底。

## 五、档位与降级（判定一次，CSS 只读结果）

启动时算一次档位，写到容器上一个属性（如 `body[data-glass-tier]`），CSS 只读它；⛔ 在多个 `@media (prefers-*)` 分支里散写玻璃规则——那样四种降级下各是什么状态，没人能机械核对。

| 档 | 进入条件 | backdrop | blur 上限 | 真折射 |
|---|---|---|---|---|
| **T0 默认** | 无条件 | ≤3 | ≤12px | 0 处 |
| **T1 实况** | 用户显式开 | ≤3 | ≤12px | 每屏 ≤1 处，且仅 Chromium |
| **T2 低功耗** | 用户主动降，或任一降级信号命中 | ≤2 | ≤8px | 0 处 |

降级四件套（**缺一条都不算有降级**）：

| 信号 | 处置 |
|---|---|
| `prefers-reduced-motion: reduce` | 强制 T0（动效全停，保留静态玻璃） |
| `prefers-contrast: more` | 强制 T2，玻璃转实底＋对比描边 |
| `prefers-reduced-transparency: reduce` | 降一档；⚠️ 只在 Chromium 118+ 生效，Safari 不支持、Firefox 113+ 默认关闭，**不可单独当依据** |
| `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` | 强制 T2 ＋ 实底 |

**引擎边界**：`backdrop-filter: url(#filter)` 的真折射只有 Chromium 渲染，Safari / Firefox 拿到的是不滤镜的原始帧。所以非 Chromium 必须自动落回模糊档，⛔ 留一条永不生效的规则。WebGPU 已全引擎 ship 也不解决这件事——采不到 DOM 是安全模型限制，不是算力限制。

## 六、动效铁律

1. **只动 `transform` 与 `opacity`**。blur／backdrop 是最贵的绘制属性之一，**⛔ 永不逐帧动模糊**；材质到场用 opacity ＋ 轻微 scale 近似。
2. 高频操作（键盘、翻页、点击切换档）走 ≤160ms 的极短过渡或瞬切，不做表演式动画。
3. 出场与进场对称：从哪来回哪去；被打断时从**屏幕当前值**续动画，不是跳到目标值。
4. `will-change` 只在动画前临时挂，**结束即摘**；⛔ 常驻多层。
5. 换档改继承变量会触发全树样式重算：变量作用域挂在玻璃层或容器上，别铺到 `:root` 之外到处覆盖。

## 七、做不到的部分明说

- 浏览器读不到最终渲染结果，「边缘实时反光＋随下方图层自动调色」这类效果纯 CSS 复刻不了；做不到就放一块固定假反光，⛔ 声称是实时。
- 曲率连续的平滑圆角给不出来，`border-radius` 只是圆弧，并排看有差别（几何见 [圆角几何](corner-geometry.md)）。
- 玻璃下的字用半透明前景＝把可读性交给底：底是图就忽明忽暗。文字用实色，或放到实底层上。

## 八、命令

```bash
python3 scripts/glass_audit.py page.html          # 人读报告；有 E 级退出码 1
python3 scripts/glass_audit.py src/ --json        # 批量，机器读
python3 scripts/glass_audit.py page.html --tokens # 附一套标准玻璃变量块，可直接贴
```

它查：同屏 backdrop 层数、blur 上限、玻璃叠玻璃、只有 blur 没底、缺描边与内高光、玻璃上文字过淡、`transition/animation` 动 backdrop、`will-change` 常驻、降级缺失或只押 `prefers-reduced-transparency`。**⛔ 它不判好看**：数值全过只说明没犯机械错，视觉仍要取证看截图。

## 九、失败样本

- 玻璃压纯色：没有可折射的东西，效果塌成一块灰蒙版 —— 换背景或别做玻璃。
- 用 blur 冒充玻璃：没有底色、没有描边，边缘散开，文字失读。
- 同屏四层玻璃：每层一次全屏采样，滚动和转场一起掉帧。
- 轻半透明叠轻半透明：底下糊成灰块，读作「脏」，不是「厚」。
- 只押 `prefers-reduced-transparency` 做降级：Safari 不支持、Firefox 默认关闭，等于没有降级。
- 给 `backdrop-filter` 写 `transition`：模糊逐帧重算，必掉帧。
- 非 Chromium 还留着真折射规则：那条规则永远不生效，验收时会误以为「已经做过真折射」。

## 十、自检（本卷）

`python3 scripts/glass_audit.py tests/fixtures/glass-good.html` 应通过（退出码 0）；`glass-bad.html` 应至少报出 blur 超限、玻璃叠玻璃、同屏超账、动 blur 四类 E。判据变更时先改脚本再改本卷，两者对不上就算本卷腐化。
